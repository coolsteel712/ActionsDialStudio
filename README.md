# ActionsDialStudio
(Not available yet) Replacement of IDO's Watch Face Designer. - ActionsDialStudio is an open-source watch face editor for VeryFit smartwatches released 2022 and newer.

## Confirmed release date
Early December 2026 to Late January 2027

## Supported Widget Rendering Types
- Font (For VeryFit smartwatches using LVGL)
- Images (e.g. g13 -> 0.png, 1.png, etc.)

## Supported Devices
- GTX02
- GTX03
- GTX10
- ID207
- IDB03
- IDW13
- IDW17
- IDW18
- IDW20

ActionsDialStudio also supports the following Kieslect smartwatches:
- KS2

C++, Qt 6
